# 工具包

配合 [`../演示视频制作标准.md`](../演示视频制作标准.md) 使用。

---

## 一、这里有什么

| 文件 | 作用 |
|---|---|
| **`演示页-模板.html`** | **最小可运行模板**（3 幕）。照着改就能出自己的片子 |
| `make.sh` | **出片主入口**：解析时间轴 → TTS → 混音 → 逐帧抓取 → SRT → 编码 |
| `capture.js` | 录屏：CDP 连接 headless Chrome，按 `__seek(t)` 逐帧截图 |
| `stills.js` | 按时刻抓静帧 —— **日常改图核对的主力工具** |
| `shot_static.js` | 静态页（非逐幕页）整页截图 |
| `interactive.js` | 页面的翻幕/自动播放交互（可选） |
| `synth.py` | **统一语音合成接口**（tencent / edge / say 三档，自动选择）|
| `tencent_tts.py` | 腾讯云 TTS 底层实现（被 synth.py 调用）|
| `base.css` | 基础骨架样式（`.wrap` / `.s-topbar` / 配色变量…） |
| `check-env.sh` | 环境自检（ffmpeg / node / Chrome / TTS provider）|

## 二、依赖

```bash
# ffmpeg（需含 libx264；不需要 libass，字幕烧在页面里）
brew install ffmpeg

# node ≥ 22（自带 WebSocket，CDP 用）
node -v

# Google Chrome（headless 录屏用）
ls /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome
```

确认 ffmpeg 能力：

```bash
ffmpeg -encoders 2>/dev/null | grep -E "libx264|aac"
```

## 三、起一个新项目（3 步）

### 1. 建目录

`make.sh` 假定这样的结构（脚本放 `build/`，页面放上一层）：

```
我的视频/
├── 演示页.html              ← 你的页面（从 工具/演示页-模板.html 复制改）
└── build/                   ← 把本目录的脚本都拷进来
    ├── make.sh
    ├── capture.js
    ├── stills.js
    ├── shot_static.js
    ├── tts.py
    ├── base.css
    ├── frames/              ← 自动创建
    └── audio/               ← 自动创建
```

```bash
mkdir -p 我的视频/build/frames 我的视频/build/audio
cp 工具/*.js 工具/*.py 工具/*.sh 工具/*.css 我的视频/build/
cp 工具/演示页-模板.html 我的视频/演示页.html
```

### 2. 配 TTS 凭证

`tts.py` 默认从环境变量 `TTS_ENV` 指定的 `.env` 读腾讯云密钥。改成你自己的路径：

```bash
export TTS_ENV=~/.config/live-video/.env
# .env 内容：
#   TENCENT_SECRET_ID=xxx
#   TENCENT_SECRET_KEY=xxx
```

> ⚠️ **导出方法**：在项目目录放一个 `.env`，首次运行时复制到项目目录之外的自有目录。
> 换机器或交付外部时替换为自己申请的腾讯云 TTS 子账号密钥。
> **不改配音则完全不需要凭证** —— 直接把现成的 `audio/` 音轨随包交付即可。

### 3. 先量时长，再填 `data-dur`

页面里先随便填时长，然后用 `tts.py` 逐幕量出真实秒数：

```bash
cd 我的视频
python3 - <<'PY'
import sys, re, io, subprocess
sys.path.insert(0, 'build')
from tencent_tts import tts, load_env
env = load_env()
html = io.open('演示页.html', encoding='utf-8').read()
for i, b in enumerate(re.findall(r'<section class="scene.*?</section>', html, re.S), 1):
    vo = re.search(r'data-vo="([^"]*)"', b).group(1)
    d, _ = tts(vo, "502005", speed=0.0, env=env)
    open('/tmp/_m.mp3','wb').write(d)
    dur = float(subprocess.run(["ffprobe","-v","error","-show_entries",
                                "format=duration","-of","csv=p=0","/tmp/_m.mp3"],
                               capture_output=True, text=True).stdout)
    print("幕%02d  TTS %.2fs  →  data-dur=\"%.1f\"  (0.30 + %.2f + 0.60)" % (i, dur, dur+0.9, dur))
PY
```

把算出的值填回每幕的 `data-dur`。

## 四、日常命令

```bash
cd 我的视频

# ① 改完页面，抓静帧核对画面（最常用）
node build/stills.js 演示页.html /tmp/check "3,8,15,22"

# ② 出片（含字幕）
HTML=演示页.html OUT=成片.mp4 SRT=字幕.srt bash build/make.sh

# ③ 出无字幕版：先生成去字幕副本
python3 -c "
import io; s=io.open('演示页.html',encoding='utf-8').read()
io.open('演示页-无字幕.html','w',encoding='utf-8').write(
  s.replace('</head>','<style>#vsub{display:none !important}</style></head>',1))"
HTML=演示页-无字幕.html OUT=成片-无字幕.mp4 SRT=/tmp/x.srt bash build/make.sh

# ④ 派生 1.2 倍速（音高不变）
ffmpeg -i 成片.mp4 -filter_complex "[0:v]setpts=PTS/1.2[v];[0:a]atempo=1.2[a]" \
  -map "[v]" -map "[a]" -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart 成片_语速1.2倍.mp4

# ⑤ 音量验收
ffmpeg -i build/audio/mix.wav -af volumedetect -f null /dev/null 2>&1 | grep volume
```

| 第 3 幕 | **内嵌 SVG 图标**（禁止 emoji）|

## 六、改模板时最容易踩的坑

完整清单见标准文档第十章，这里列**最致命的三个**：

### ① 入场动画不能用 JS

```html
<!-- ❌ 录屏定位不到，会闪或者停错状态 -->
<div id="x">…</div>
<script>setTimeout(()=>x.style.opacity=1, 800)</script>

<!-- ✅ -->
<div class="au" style="--d:0.80s">…</div>
```
```css
.scene.play .au { animation: au .78s both; animation-delay: var(--d, 0s); }
```

### ② 门控选择器要写复合形式

```css
.scene.play .v1s2 .card { }   /* ❌ 不生效 */
.scene.play.v1s2 .card { }    /* ✅ 同一个元素上的多个类 */
```

### ③ `curIdx` 必须初始化成 `-1`

```js
var curIdx = -1;   // ← 写成 0 的话，第一幕永远不显示
```

`__seek` 靠"幕号变了"才切 `.active`/`.play`。若初值是 `0`，`t=0` 时 `idx === curIdx`，
切幕分支被跳过 → `.play` 加不上 → 第一幕的内容**永远停在 `opacity:0`**。
（现象很迷惑：**只有第一幕空白，后面全正常**。）

## 七、自己搭一套的最小验证顺序

别一上来就写 20 幕。按这个顺序验证：

1. **先写 1 幕** → `stills.js` 抓一张 → 确认画面对
2. **加到 3 幕** → 确认切幕、字幕、动画都对
3. **跑一次 `make.sh`** → 确认出片链路通（这一步会暴露环境问题：ffmpeg / Chrome / TTS 凭证）
4. **再开始堆内容**

> 第 3 步一定要早做。TTS 凭证、Chrome 路径、ffmpeg 能力这三个问题，越晚发现越费时间。
